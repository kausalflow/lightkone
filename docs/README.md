# Lightkone documentation

Lightkone is a reference manager for research papers that runs in your
browser. Your papers, PDFs, highlights and notes live as plain files in
storage you choose, and Claude can help you read, search and cite them with
your own key.

## Start here

- [Getting started](GETTING-STARTED.md): the first ten minutes.
- [Moving from Paperpile](PAPERPILE.md): bring your library, folders, labels and PDFs over.
- [Where your library lives](STORAGE.md): this browser, Cloudflare R2, AWS S3, MinIO, or a private GitHub repository, set up step by step.

## Using Lightkone

- [Reading and highlighting](READING.md): the PDF reader, highlights, notes, Explain, and export to Obsidian.
- [Finding papers](FINDING.md): search and its filters, full text, equations, chats with Claude (Ask, comparing papers, organizing chats), New on arXiv and the citation map.
- [Writing with your library](WRITING.md): citations in any journal style, LaTeX and Overleaf, a .bib for a manuscript.
- [Sharing and devices](SHARING.md): several devices, shared libraries, the phone app.
- [Claude and other AI apps (MCP)](MCP.md): use your library from Claude, Claude Code or any MCP app.
- [Your data](PRIVACY.md): what is processed where, and what leaves your browser.
- [Questions and fixes](FAQ.md): common questions, and what to do when something goes wrong.

## Running your own

- [Hosting](HOSTING.md): deploy Lightkone for yourself or a team.
- [Releasing](RELEASING.md): staging, version tags, and checking a site runs a release's exact code.
- [Plugins](PLUGINS.md): add storage, lookups, importers and actions.
- [Architecture](ARCHITECTURE.md): how it fits together.
